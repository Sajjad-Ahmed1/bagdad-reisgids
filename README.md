# Bagdad Reisgids — النسخة المحلية بالمحتوى النهائي

## فتح الموقع
افتح OPEN-PREVIEW.cmd، ثم http://127.0.0.1:4173/ . لإيقاف السيرفر أغلق نافذة التشغيل أو استخدم Ctrl+C فيها.
بديل دون سيرفر: افتح dist/index.html مباشرة. التنقل والبحث يعملان لأن البيانات محلية في data.js.

## ما تحتويه النسخة
واجهة هولندية متجاوبة، Home، Places overview مع البحث والفلاتر والفرز وتحميل المزيد، 8 صفحات أماكن، Categories overview و4 صفحات فئات، About/Practical، Privacy، Cookies، Search/No results، 404، Header/Footer، ومعرض صور قابل للتكبير، وصفحة Beeldcredits.
النماذج محاكاة: لا ترسل ولا تحفظ بيانات. إعدادات الكوكيز تشرح أن النموذج لا يستخدم كوكيز.

## مصدر المحتوى
source/DOC-20261018-WA0004.pdf — محتوى Part 2 النهائي، 27 صفحة، بتاريخ 18 أكتوبر 2026.
استُخرجت منه Destination واحد، 8 Places، 4 Categories، 4 Reviews تجريبية، و9 Media Assets بالنصوص وبيانات المصادر والحقوق.
التقييمات موسومة Testdata وليست تجارب حقيقية. لا تُنشر كتقييمات حقيقية عند الانتقال إلى WordPress.
الصور هي الصور المضمنة في PDF؛ لا تمثل الأصول عالية الدقة. حافظنا على بيانات المصور والترخيص وalt والروابط. راجع Beeldcredits في الموقع.
مبالغ الدخول الفارغة بقيت «غير مذكورة»، ولم تُستبدل ببيانات مخترعة. شارع المتنبي وحده له قيمة 0 في المصدر.
بيانات السفر والسلامة والطوارئ معروضة بتاريخ المصدر وليست تحققاً آنياً. رابط مراجعة النصيحة الرسمية موجود في المعلومات العملية.
نصوص Privacy/Cookies نُقلت من Part 2 مع توضيح منفصل لسلوك النموذج المحلي. نموذج التواصل المذكور في النص الأصلي غير نشط هنا.

## الملفات
- dist/index.html: القالب العام.
- dist/style.css: الهوية والتنسيق والاستجابة.
- dist/app.js: قوالب الصفحات والتفاعلات.
- dist/data.js: المحتوى المستخرج جاهز للاستخدام دون سيرفر.
- dist/content.json: بيانات منظمة قابلة للنقل والتحويل.
- dist/assets/: الصور التسع المستخرجة دون تغيير ملفاتها.
- source/: الملفات الثلاثة الأصلية والنص المستخرج.
- WORDPRESS-HANDOFF.md: خريطة الانتقال ومتطلبات Part 3 وحدود هذه النسخة.
